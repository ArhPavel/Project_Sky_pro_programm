ООП Каталог товаров (E-commerce)

Проект на Python, реализующий объектно-ориентированную модель каталога товаров для интернет-магазина с применением абстрактных базовых классов, множественного наследования и миксинов.

## Описание и функциональность

### Иерархия классов и архитектура:
* **`BaseProduct`** — базовый абстрактный класс (`ABC`) для всех товаров, задающий обязательный интерфейс (`price`, `__str__`, `__add__`, `@classmethod new_product`).
* **`PrintMixin`** — класс-миксин, выводящий в консоль информацию о создании объекта (`__repr__`) через множественное наследование.
* **`Product`** — базовый класс товара (название, описание, цена, количество).
* **`Smartphone`** — класс смартфона, расширенный характеристиками: производительность (`efficiency`), модель (`model`), память (`memory`), цвет (`color`).
* **`LawnGrass`** — класс газонной травы, расширенный характеристиками: страна-производитель (`country`), срок прорастания (`germination_period`), цвет (`color`).
* **`BaseOrderCategory`** — абстрактный класс для сущностей, содержащих товары.
* **`Category`** — класс категории товаров с автоматическим подсчетом общего количества категорий и уникальных товаров.
* **`Order`** — класс заказа на покупку определенного товара с расчетом итоговой стоимости.

### Ключевые особенности:
* **Защита данных:** приватные атрибуты цен и списков товаров с доступом через `@property` и сеттеры с валидацией.
* **Ограничение сложения (`__add__`):** суммировать общую стоимость остатков можно только у товаров строго одинакового класса (попытка сложить разные классы вызывает `TypeError`).
* **Защита категорий и заказов:** метод `add_product` принимает только экземпляры `BaseProduct` и его наследников.

## Установка

### *Клонируйте репозиторий*:

git clone [https://github.com/ArhPavel/Project_Sky_pro_programm.git](https://github.com/ArhPavel/Project_Sky_pro_programm.git)
cd Project_Sky_pro_programm

### Установите зависимости через Poetry:

Bash
poetry install

### Запустите демонстрационный скрипт:

poetry run python main.py
