# ООП Каталог товаров (E-commerce)

Это проект на Python, реализующий базовую структуру каталога товаров для интернет-магазина с использованием принципов объектно-ориентированного программирования (ООП).

## Описание
Проект позволяет создавать товары и группировать их по категориям. Реализован автоматический подсчет общего количества созданных категорий и уникальных товаров во всех категориях.

**Реализованные классы:**
* `Product` — описывает конкретный товар (название, описание, цена, количество в наличии).
* `Category` — описывает категорию товаров (название, описание, список товаров).

## Структура проекта
* `src/clases.py` — основной модуль с классами `Category` и `Product`.
* `main.py` — (или ваш файл запуска) скрипт для демонстрации работы классов и вывода данных в консоль.
* `tests/test_clases.py` — модульные тесты для проверки логики работы классов.
